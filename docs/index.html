Auricle

Behind the project

Why I built Auricle

Mainstream desktop music apps often used far more RAM and GPU than I wanted while gaming or working. The open-source options I tried either relied on heavy embedded browsers or missed features I cared about, so I built Auricle in Rust and Slint — and later paired it with a native Android companion that syncs peer-to-peer.

The goal is a clean, responsive player with low background overhead, zero accounts, and zero hosted servers. Feedback on usability, playback, Party sync, or resource usage is always welcome via Windows issues or Android issues.

Unsigned Windows builds note: Because Auricle is an indie open-source release without a commercial Authenticode certificate yet, Windows SmartScreen or heuristic antivirus scanners may warn on the installer. You can verify checksums, inspect the source code, or build from source — never disable antivirus protection to test software.

FAQ

Common questions

Can't find an answer? Open an issue on GitHub.

How does Listen Together (Party Sync) work without a server?

Party Sync uses Iroh encrypted peer-to-peer QUIC connections with automatic relay fallback across Wi-Fi and mobile data. Starting a Party generates a private auricle://party/... invite link containing a random room secret; only playback commands, timestamps, and track IDs are synced between peers.

Does Auricle bundle or distribute yt-dlp / ffmpeg / Deno?

No. On Windows, Auricle never bundles third-party tools. The optional in-app installer downloads yt-dlp, ffmpeg, and Deno directly from their official GitHub releases with your consent, or you can use your own copies on PATH. Once yt-dlp is installed, Auricle keeps it updated at most once a week in the background.

What data does Auricle collect?

None is sent to the developer: there are no accounts, telemetry, or analytics. Your library, history, and settings stay on your device. Read the privacy policy for full details. Browser cookies are off by default unless you enable them in Settings.

How do I build from source?

Windows requires Rust ≥ 1.91 and the MSVC C++ Build Tools; clone californiaAlmonds/auricle and run cargo run --bin auricle. Android build steps (Gradle + cargo-ndk) are documented in californiaAlmonds/auricle-android.
